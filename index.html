A hardware-aware optimization engine: profile, benchmark, change only what's supported, verify, roll back.

Consoles feel consistent because developers target one known configuration. PCs vary endlessly — CPU, GPU, drivers, memory, display modes. Optimize automates the loop PC players do by hand: measure first, change only supported settings reversibly, then benchmark again. It never promises console-level performance or a fixed FPS gain.

Measure, change, verify — in a closed loop.

No registry magic and no guesswork. Every pass is bounded, catalog-checked, and reversible, and the loop stops at the target, the test budget, or the point where gains become negligible.

  • 01Profile the PC. Read-only detection of CPU, GPU, VRAM, RAM, display, and driver version through supported OS and vendor interfaces — no admin rights, no assumptions.
  • 02Benchmark the game. Repeatable baseline runs capture average FPS, 1% lows, and raw frame times — with run-to-run variance reported, not hidden.
  • 03Search supported settings. Estimate the likely bottleneck, then test a bounded set of candidates drawn only from the game's documented settings catalog — one change at a time.
  • 04Apply reversibly. Validated values, atomic writes, and a verified backup taken before anything changes; every change lands in an audit log.
  • 05Verify & roll back if not better. Re-benchmark under the same conditions. Keep improvements that beat benchmark variance; restore the exact original configuration otherwise.

Principles before performance.

The project principle, straight from the README: measure before changing anything; apply only supported, reversible changes, then benchmark again. Never promise console-level performance or a fixed FPS gain.

📏

Measure first

Nothing changes until there's a baseline. Recommendations are validated by measurement, and gains inside run-to-run variance are reported as inconclusive — not as wins.

🧩

Supported changes only

Only settings a game's adapter catalog documents, with validated values. No binary edits, no memory patching, no anti-cheat interference, no overclocks, no undocumented registry tweaks.

↩️

Reversible by default

Every session starts from a verified backup, writes are atomic, and one command restores the exact original configuration — rollback is built in, not bolted on.

🎯

No magic numbers

No promised FPS gains and no console guarantees. Results depend on the game, hardware, driver, and benchmark conditions — the tool reports uncertainty instead of hiding it.

Where it honestly stands.

v0.1.0 is a Milestone 1 prototype: the full loop — profile, backup, baseline, bounded candidate trials, verdicts, rollback — runs end to end and is tested in CI (84 tests) against a synthetic game, with the Windows-specific collectors behind the same interfaces awaiting validation on real hardware.

v0.1.0Milestone 1 prototype. Benchmark-and-rollback works against a synthetic game: local SQLite profile database, HTML reports, JSONL audit log, one-click restore.
Phase 0Feasibility spike. Pick one real game with a repeatable benchmark; validate telemetry capture and safe, restorable settings on real Windows machines.
Phase 1Instrumentation prototype. Hardware detection, frame-time capture, saved metadata, average-FPS / 1%-low charts, run-to-run variance checks.
Phase 2One-game optimizer. The first real game adapter, safe-settings validation, a small candidate set, rejected crashes and regressions, a verified improvement.
Phase 3Desktop UX. Game selection, target profiles, a preview of planned changes, and explicit Apply / Re-test / Restore controls.
Phase 4More games and hardware. Adapters one game at a time; AMD and Intel tuning where interfaces allow; profile import/export; opt-in community profiles.
Phase 5Smarter optimization. Sample-efficient search and AI-generated explanations — with every change still validated by deterministic code.

The MVP scope is deliberately narrow: Windows desktop, one supported game, NVIDIA GPUs first, read-only hardware detection, a short documented list of safe settings, manual benchmark fallback, backup and rollback. The full plan lives in the README.

Get Optimize.

A Python package — 3.10+, standard library only — installed from source while it's a prototype. The first target is Windows; the loop itself runs on any OS so the pipeline stays tested in CI.

git clone https://github.com/KSWORK2001/Optimize && cd Optimize && pip install -e .
Releases

Then run the loop: python -m optimize demo — full loop, restores your original config by default. Add --apply to keep the winning configuration, or python -m optimize report for an HTML report of the last session.
